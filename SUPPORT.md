# Getting help

- **Questions and setup help:** start a thread in [Discussions](https://github.com/opensphincter/openspoofen/discussions). Include your Pi model, OS release, provider and topology.
- **Bugs:** open an [issue](https://github.com/opensphincter/openspoofen/issues/new/choose) with the bug report form.
- **A provider you want supported:** use the provider request form.
- **Security problems:** follow [SECURITY.md](SECURITY.md), not the issue tracker.

The [documentation index](docs/README.md) covers deployment, provider accounts and testing without hardware.

OpenSpoofen is maintained in spare time, so replies can take a few days.
