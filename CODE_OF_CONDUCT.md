# Code of conduct

OpenSpoofen follows the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/). Everyone taking part in issues, pull requests, discussions and other project spaces is expected to follow it.

## Reporting

To report behaviour that breaks the code of conduct, contact the maintainer, [garzione](https://github.com/garzione), privately, or use GitHub's **Report content** option on the comment or issue. Reports are handled in confidence.
